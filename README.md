# Qumran
Dead Sea Scrolls

Organized into two projects:

- `Biblical Alignment/` — Swanson-style composite text of the biblical Dead Sea Scrolls aligned to the Lexham Hebrew Bible (with Nick Meyer).
- `English Translation/` — the Lexham English Dead Sea Scrolls / *The Dead Sea Scrolls: A New English Translation*, including the `original/` transcriptions and the conversion scripts used by the workflows in `.github/`.
- `Reference/` — DJD indexes and other shared reference material.
- `Admin/` — contracts and tax paperwork.
